AMANAT BY ANCHAL — WEBSITE PACKAGE

Files
- index.html: Home page, searchable product catalogue, category filters, cart and WhatsApp checkout.
- about.html: About / Our Story.
- contact.html: Contact form which prepares a WhatsApp message.
- faq.html: Frequently asked questions.
- shipping.html: Shipping and returns starter policy.
- privacy.html: Privacy notice for the static website.
- terms.html: Terms and conditions starter wording.

Before publishing
1. In index.html and contact.html, replace WHATSAPP_NUMBER = "91XXXXXXXXXX" with the shop's real WhatsApp number, digits only and including the country code. Example format: 919876543210.
2. Replace all demo product names, prices, descriptions and emoji visuals in index.html with the real product catalogue and photographs.
3. Review shipping.html, privacy.html and terms.html carefully. Business delivery, payment, refund, privacy and cancellation practices have not been provided, so these pages are starter copy and need owner approval before going live.
4. Confirm the Instagram profile link in contact.html matches the business's official account.
5. Keep all HTML files in the same folder. To deploy on GitHub Pages, upload the files to the repository and enable Pages for the desired branch/folder.

The static site does not collect payments or store submitted contact forms. The cart is client-side; WhatsApp opens with a pre-filled message that the customer must review and send.
